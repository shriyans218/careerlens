# CareerLens API Reference

Full interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI)
and `/redoc` when the server is running.

## Endpoints

### GET /api/health
Returns service status and model load state.

### GET /api/dashboard
Returns precomputed model-comparison macro-F1 scores and a 2D t-SNE
projection of the training set. 404 if `model_out/dashboard_data.json`
hasn't been generated.

### POST /api/predict-resume
Multipart file upload (`pdf`/`docx`/`txt`). Returns `top_prediction`,
`top_5`, `tech_top_5`, `resume_text`, `parsed_entities`, `resume_point`,
`model_breakdown`, `trait_scores`.

### POST /api/predict-scores
JSON body with 8 trait scores (0–20 each). Returns `top_prediction`,
`top_5`, `resume_point`.

### POST /api/gap-report
JSON body: 8 trait scores + `career` (free text, resolved against known
roles) + optional `resume_text`. Returns `gaps` (trait-level) and,
when `resume_text` is supplied, `technical_gaps` (skill-level).

### GET /api/careers
Returns all known career/category names for autocomplete.

## CLI

```
careerlens predict-resume <file>
careerlens predict-scores --linguistic 12 --musical 8 ...
careerlens gap-report <file> --career "Data Scientist"
careerlens serve --port 8000 [--reload]
```
